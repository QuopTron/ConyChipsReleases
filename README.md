# ConyChips Releases

Binarios publicados de ConyChips para Android.

- `app-arm64-v8a-release.apk`: telefonos de 64 bits (recomendado).
- `app-armeabi-v7a-release.apk`: telefonos de 32 bits.

El codigo fuente no vive en este repositorio. La app comprueba la ultima release desde su pantalla de inicio para actualizarse.
